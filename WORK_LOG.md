## Expo Go preview — October 24, 2026

Added runtime adapter selection using Expo's isRunningInExpoGo helper. Expo Go never evaluates the native speech adapter and instead offers manual text entry with a short explanation; microphone, language-model and device-settings controls are hidden there. Development builds still use the existing on-device recognizer. The same SQLite/editor/synthesis paths serve both modes. Added root/workspace start:go scripts without adding dependencies.

Validation: npm run check passed (app/server/test TypeScript, ESLint and 26 tests across 8 files). New tests confirm the native adapter is not evaluated in Expo Go, no speech events/permissions are generated by the manual adapter, and native builds construct the real adapter. Existing persistence and synthesis workflow tests still pass. Actual Expo Go/iPhone UI testing remains pending; the smoke checklist and separate-storage caveat are in README.md and docs/DEVICE_TESTS.md.

Android and iOS Hermes bundle exports also passed after the adapter changes.

The root start:go command launched Metro successfully on port 8083 in an offline/CI smoke test, then was stopped. The sandbox blocked React Native DevTools' user-cache download, so Metro used its fallback DevTools; this did not prevent startup. Normal interactive use should omit CI/offline overrides.
